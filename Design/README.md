# Ayre application icon

`AppIcon.svg` is the editable source for the approved two-line `ay` / `re` wordmark icon. It uses the circular letter modules and asymmetric curved terminals developed for Ayre, in ivory on charcoal.

The macOS icon images in `App/Assets.xcassets/AppIcon.appiconset` are raster exports at each catalog size (16, 32, 128, 256 and 512 points at 1x and 2x). Preserve the transparent area outside the rounded tile when exporting. Xcode compiles this catalog into the app's `AppIcon.icns`.

Design explorations in the local `output/` directory are not app resources.
