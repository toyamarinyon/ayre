# Sparkle distribution preflight: v0.2.2

This records an independent local check of the signed draft generated by the GitHub Actions release workflow. The workflow run passed on source commit `50c476157f49cbfce9a89a6250a3823537221821`:

- [Signed macOS release run 39739536441](https://github.com/toyamarinyon/ayre/actions/runs/39739536441)
- [Draft release v0.2.2](https://github.com/toyamarinyon/ayre/releases/tag/untagged-852abb10d2873d44aec0)

GitHub reports this as a draft (`isDraft: true`, `publishedAt: null`) with API `tag_name` `v0.2.2` and target `50c476157f49cbfce9a89a6250a3823537221821`. The `untagged-...` path is the draft page URL; the appcast download URL correctly uses the eventual stable tag `v0.2.2`. No public release was published.

The downloaded assets are in `build/verification/release-v0.2.2/`:

| Asset | Size | SHA-256 |
| --- | ---: | --- |
| `Ayre-0.2.2-macOS.zip` | 1,751,207 bytes | `fc112a8c3132f60e8f457337dcdcf68cd3bb132824433037488d6965c253c22f` |
| `appcast.xml` | 793 bytes | `ddb3c366a59e13d0ff78ba4f50b2d36a44da189b98fb63d982a3f6f50942bb51` |

`shasum -a 256 -c SHA256SUMS` passed for both assets. The ZIP contains only the `Ayre.app` root; its 128 entries and six relative symlinks remain within that app. The package was extracted with `ditto -x -k` to a fresh temporary directory for inspection.

`python3 scripts/verify-package.py <extracted-app> --distribution` passed. It confirmed app version `0.2.2`, build `2`, independent CLI version `0.2.1`, the updater configuration and embedded Sparkle framework, universal nested Mach-O binaries, no `get-task-allow`, and the bundled CLI behavior.

These macOS security checks passed on the extracted app:

```text
codesign --verify --deep --strict --verbose=2 <extracted-app>
xcrun stapler validate <extracted-app>
spctl --assess --type execute --verbose=2 <extracted-app>
```

The app signature was valid on disk, the notarization ticket validated, and Gatekeeper accepted it as `Notarized Developer ID`. All inspected Mach-O paths (including framework symlink aliases) contained both `arm64` and `x86_64` slices and had TeamIdentifier `2KH86RU7AS`, matching the outer Ayre app. The Apple team secret was not read.

`python3 scripts/verify-appcast.py --app <extracted-app> --appcast build/verification/release-v0.2.2/appcast.xml --archive build/verification/release-v0.2.2/Ayre-0.2.2-macOS.zip --tag v0.2.2` passed. The item describes build `2`, marketing version `0.2.2`, minimum macOS `14.0`, the versioned ZIP URL, its exact length, and a 64-byte EdDSA signature.

The embedded `SUPublicEDKey` matched the registered GitHub Actions public variable. The public value was read from the ignored local verification file for equality comparison and was not displayed. No private signing key was accessed. An independent CryptoKit Ed25519 verification using the embedded public key accepted the appcast signature over the downloaded ZIP bytes. This verifies the archive signature trust anchor without the private key. The feed itself is not signed; only the update archive carries an EdDSA signature.

The package was not launched or installed. A manual downloaded-app smoke test and review of the draft release page remain pending before any public publication.
